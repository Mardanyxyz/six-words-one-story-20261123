An original six-word story, written as a small deterministic TypeScript
program. Running `node main.ts` writes exactly one six-word story to
`/output/entry.txt` — six words, under sixty characters, no trailing
newline. The program self-checks the word count and the character limit
before writing, and reads the file back to verify it matches the story
byte for byte.

A man comes home after being gone — and finds the door will not open
for him anymore. The rest of the story is left unsaid.
